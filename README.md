# Resume–Job Matching & Skill Gap Analyzer

## What the Project Is
- Takes a user's resume and a job description as input
- Analyzes the resume against the job description
- Tells the user how well the resume matches that job

## What Problem It Solves
- Helps users understand how well their resume matches a specific job
- Helps users improve their resume based on the job description

## Status
Work in progress — early project setup stage.
